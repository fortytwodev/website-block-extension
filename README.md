## Website block extension
Simple website blocking extension for Chromium browsers

### Description
An extension that blocks distracting websites. Just by adding a website URL to the list, you can't request access to that website.

### Getting started
#### Dependencies
 - There are no third-party dependencies
 - Manifest v3
#### Installing
 - [Link](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked) to official Chrome extension installation
